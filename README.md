# Global Retail & Logistics Analytics

## Project Overview
This analysis evaluates global omnichannel retail data, mapping order logs to product and country registries to audit performance, supply chain lead times, and sales trends.

## Key Takeaways
* **Financial Performance:** Generated **\$1.7B** in revenue and **\$500M** in profit, centered mainly in Europe.
* **Product Margins:** **Office Supplies** brings the highest revenue, while **Cosmetics** generates the highest margin.
* **Supply Chain:** Average lead time is **~25 days**, with no direct impact on unit profitability.
* **Channels & Trends:** Sales are split evenly (50/50) between Online and Offline channels, with a post-2012 decline in overall volume.

## Tech Stack
* Python (Pandas, Matplotlib, Seaborn)
